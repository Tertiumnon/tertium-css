Navigation

A sticky navigation bar with brand, menu items, and action buttons. Resize the page: links move one at a time into the three-dot menu when they no longer fit.

<nav class="navbar navbar--responsive">
  <div class="navbar-inner">
    <a href="#" class="navbar-brand">Logo</a>
    <ul class="navbar-menu" id="main-navigation">
      <li class="nav-item"><a href="#" class="nav-link active">Home</a></li>
      <li class="nav-item"><a href="#" class="nav-link">About</a></li>
      <li class="nav-item navbar-overflow" hidden>
        <button class="btn btn--sm navbar-toggle" type="button" aria-label="More navigation"
          aria-controls="main-navigation-overflow" aria-expanded="false">···</button>
        <ul class="navbar-overflow-menu" id="main-navigation-overflow"></ul>
      </li>
    </ul>
    <div class="navbar-actions">
      <button class="btn">Sign In</button>
    </div>
  </div>
</nav>

The demo script uses ResizeObserver to move links between the main menu and the overflow list, and updates aria-expanded when the toggle is pressed.
